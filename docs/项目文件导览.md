| 文件 | 用途 |
|---|---|
| `donut_studio.blend` | 可编辑甜甜圈、糖霜、310 粒动画糖粒和 8 秒运镜工程 |

| `LICENSE-CODE` | MIT 代码许可证全文 |
| `LICENSE-ASSETS.md` | 模型、动画、渲染与文档的 CC BY 4.0 授权 |
| `CONTRIBUTING.md` | 提交分组、中文说明、验证与 AI 共同作者约定 |

## scripts：制作过程

| 文件 | 用途 |
|---|---|
| `build_donut.py` | 程序化生成面包、糖霜、糖粒、餐盘和灯光，并设置下落与运镜关键帧；重建会覆盖目标工程 |
| `render_frames.py` | Blender 内的逐帧 Cycles OptiX 渲染，写入每帧耗时及设置 |
| `benchmark_render.py` | 启动后台渲染、采样 CPU/GPU/内存、调用编码并统计总耗时 |
| `encode_video.py` | 检查 192 帧完整性，编码 H.264，随后解码整段视频进行验证 |
| `finalize_delivery.py` | 验证一次本机渲染成功后，更新视频、性能说明并调用打包流程 |
| `package_delivery.py` | 制作本机完整交付 ZIP，依赖未发布的本机安装记录等资料 |
| `verify_scene.py` | 检查 310 粒糖粒在代表帧的显现、下落、落定及相机移动 |
| `mcp_client.py` | 通过 MCP stdio 协议查询工具、向 Blender 执行代码并记录结果 |

运行范围与原机器路径见 [使用与渲染指南](使用与渲染指南.md)。这些文件保存制作流程，下载者不需要先执行它们才能打开主工程。
